# 自定义指令注册器（astrbot_plugin_custom_commands）

在 AstrBot WebUI 中维护「指令 → 固定回复」列表，插件加载时把每条指令
**真正注册进 AstrBot 的指令系统**，从而：

- 聊天中发送 `/指令` 即回复固定内容，全程不经过 LLM；
- 「QQ菜单面板管理」插件的指令选择器可以读到这些指令，
  一键同步到 QQ 官方机器人的 `/` 指令面板。

## 安装

方式一（推荐）：在 AstrBot WebUI → 插件管理 → 安装插件 → 从文件安装，
上传 `astrbot_plugin_custom_commands.zip`。

方式二：把 `astrbot_plugin_custom_commands` 文件夹整个放入
AstrBot 的 `data/plugins/` 目录，然后重启 AstrBot 或在插件管理中加载。

## 使用

1. WebUI → 插件管理 → 找到「自定义指令注册器」→ 打开配置；
2. `commands` 是一个键值对编辑器，点击「修改」→「新增键值对」：
   - **简单用法**：键填指令名（不带 `/`、不含空格，例如 `签到`），
     类型选 `string`，值填回复内容；
   - **高级用法**：类型选 `json`，值填完整配置，可同时指定描述与别名：
     ```json
     {"reply": "签到成功！", "desc": "每日签到", "aliases": "打卡,sign"}
     ```
     其中 `desc` 会显示在菜单面板插件的指令选择器中，方便挑选；
3. 保存配置后 **重载本插件**（或重启 AstrBot）使其生效；
4. 聊天中发送 `/签到` 测试，应直接收到固定回复；
   也可以发送 `/customcmd`（别名 `/自定义指令`）查看当前生效的指令列表。

> 如果习惯直接改配置文件（`data/config/astrbot_plugin_custom_commands_config.json`），
> `commands` 是一个对象，键为指令名，值为回复字符串或上述 json 对象；
> 也兼容写成对象数组（每项含 command/reply/desc/aliases 字段）。

## 配合 QQ 菜单面板管理插件（同步到 QQ 的 "/" 面板）

1. 确认「QQ菜单面板管理」插件已安装且凭证正常；
2. 打开它的管理页面 → 选择场景（c2c / group / channel / dm）→ 新建面板；
3. 点「选指令」，在列表中找到本插件（自定义指令注册器）下的指令，选中保存；
4. 在 QQ 聊天框输入 `/` 即可看到并点选这些指令。

## 注意事项

- 修改配置（增删改指令、改回复内容）后必须 **重载插件** 才生效，
  因为指令是在插件加载时注册进框架的；
- 指令名不要与其他插件的指令重名，重名时高优先级的本插件指令会优先触发；
- QQ 侧限制：指令面板最多 20 个、每面板最多 20 个按钮；
- 回复为纯文本；如需图片等富媒体，可在后续版本中扩展。
